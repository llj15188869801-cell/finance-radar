# 财讯雷达红蓝军审查记录

更新时间：2026-06-15

## 结论

本轮采用内容质量、可靠性、安全三条线做红军攻击，再由蓝军做最小可验证修复。当前主站公开页已经从“杂乱信源流水”收敛为 5 条中文财经热点，低价值 SEC 表格/申报内容不再公开展示，后台匿名访问被拒绝，自动抓取链路可运行。

## 已修复问题

- 内容噪声：SEC 低价值 filing 在源头过滤，历史低价值内容已撤回，公开页仅展示已发布且通过筛选的热点。
- 行情表述：修复“集体上涨/同步上涨”的误判，涨跌不一时不再强行写成一致方向。
- 中文展示：公开内容通过中文化保护，英文标题不会直接作为主展示文案。
- 投资提示：列表、详情和 README 都明确“仅供信息参考，不构成投资建议”。
- 行情供应商：删除“待接入授权/持牌行情供应商”口径，改为公开行情参考和延迟提示。
- 自动抓取：公开行情脉冲接入 A 股、港股、美股、原油、贵金属和板块方向。
- 事件聚类：中文标题按市场锚点、数字和标题相似度聚类，减少同一事件被 URL 差异拆碎。
- Worker 可靠性：队列并发限制为 1，运行中任务不会重入；行情抓取使用部分失败兜底。
- Worker 运行态：清理了多组旧 Worker，只保留一组新 Worker 进程链路。
- 同步安全：镜像同步使用签名、时间戳和数据库 nonce 防重放；同步 payload 会真实持久化。
- 公开权限：公开 API 只读 PUBLISHED，后台 API 匿名访问返回 401。

## 验收结果

- `npm test`：通过，9 个 Worker/内容测试、3 个 Web 测试、2 个 Domain 测试。
- `npm run typecheck`：通过。
- `npm run build`：通过。
- `npm run pipeline:run`：成功，处理并持久化 5 条热点。
- `http://localhost:3000/api/events?limit=20`：返回 5 条公开热点，非 published 为 0。
- `/api/admin/events`：匿名访问 401。
- 首页检查：未发现“表格申报、申报方、424B2、10-D、497、待接入、授权行情、持牌行情”等噪声词。
- 数据库状态：PUBLISHED 5，REVIEW 164，WITHDRAWN 624，低价值 PUBLISHED 0。

## 剩余风险

- 当前行情数据来自公开接口，可能延迟或变更，不保证等同交易所最终行情。
- 普通新闻事件仍是轻量聚类，不是完整实体级 NLP 聚类；后续可加入公司简称、股票代码和主题词库。
- 镜像同步没有 outbox 表，主库成功但镜像失败时依赖下一轮或手动补偿。
- 管理后台已有基础权限，但正式公网前还需要更完整的登录、角色和 CSRF/审计测试。
